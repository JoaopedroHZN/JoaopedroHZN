## 🧠 Sobre mim

Sempre preferi resolver problemas em vez de reclamar deles. Minha trajetória na tecnologia me levou a focar profundamente no desenvolvimento **Back-End**, onde me especializo em criar APIs RESTful seguras, performáticas e bem estruturadas.

* 🚀 Foco principal no ecossistema **Java 17/21** com **Spring Boot 3**, aplicando Programação Orientada a Objetos, Design Patterns e Arquitetura Limpa.
* 🔒 Experiência com segurança de aplicações utilizando **Spring Security**, autenticação **stateless com JWT** e criptografia **BCrypt**.
* 🐳 Prática contínua com DevOps básico e infraestrutura usando **Docker** e bancos de dados relacionais (**PostgreSQL**, **MySQL**) e NoSQL (**MongoDB**, **Redis**).
* 💡 Conhecimento versátil em front-end e scripts com **React 19**, **TypeScript**, **JavaScript** e **Python**.
* 🎯 Busco oportunidades como **Desenvolvedor Back-End Jr / Pleno** para contribuir com soluções eficientes em times de alto nível.
